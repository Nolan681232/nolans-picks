    Rules
    • Zombies score 1 when a zombie stands on the top platform, then they respawn outside.
    • If a guard touches a zombie inside the castle, guards +1 and zombies −1. That zombie goes back outside. A guard on the roof can stop a score this way.
    • If a zombie touches a guard outside the castle, guards −1 and that guard is sent back inside.
    • If a guard walks onto zombie land, guards −1 and they respawn inside. A short cooldown stops the score from draining twice.
    • Scores never go below 0. Inside the castle, the guard’s tag wins if both touch at once.
    • The host picks the ending: first to N points (default 3), or highest score when the timer runs out. A tied timer is a draw.
    • Side picks are kept when the teams can be even. If too many people pick the same side, extras are moved at random.
    • In VR, touching someone with a controller tags them. The same match works with keyboard players.
